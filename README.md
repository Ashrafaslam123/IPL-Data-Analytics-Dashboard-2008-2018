# IPL-Data-Analytics-Dashboard-2008-2018
An interactive IPL Data Analytics Dashboard analyzing match results, toss decisions, top venues, Man of the Match awards, and season winners from 2008 to 2018 using Microsoft Excel.

IPL Data Analytics Dashboard (2008–2018)
* Project Overview

This project focuses on analyzing Indian Premier League (IPL) match data from 2008 to 2018 using Microsoft Excel. The objective of the project is to transform raw match data into meaningful insights through data cleaning, analysis, pivot tables, and interactive dashboard visualizations.

The project analyzes 696 IPL matches and provides insights into team performance, match-winning trends, toss decisions, popular venues, title winners, and Man of the Match performances.

* Project Objectives

The main objectives of this project are to:

Analyze IPL match data from 2008 to 2018.
Identify the most successful teams based on match wins.
Analyze the impact of toss decisions on match outcomes.
Identify the top IPL venues based on the number of matches played.
Analyze Man of the Match award winners.
Compare team performances across different IPL seasons.
Identify IPL title winners and runners-up.
Present insights through an interactive Excel dashboard.
* Dataset Information

The dataset contains information about IPL matches played between 2008 and 2018.

Dataset Size
Total Matches: 696
Total Columns: 16
Key Data Fields
Column	Description
ID	Unique match identifier
City	City where the match was played
Season	IPL season
Date	Match date
Player of Match	Man of the Match award winner
Venue	Stadium where the match was played
Team 1	First participating team
Team 2	Second participating team
Toss Winner	Team winning the toss
Toss Decision	Decision to bat or field
Result	Match result type
Winner	Match-winning team
Win by Runs	Margin of victory by runs
Win by Wickets	Margin of victory by wickets
Umpire 1	First umpire
Umpire 2	Second umpire

* Analysis Performed
1. Match Win Analysis

Analyzed team performance based on the number of matches won.

2. Toss-Based Decision Analysis

Analyzed whether teams preferred to:

Bat first
Field first

This helps understand toss-winning strategies and match preferences.

3. Top 10 IPL Venues

Identified the most frequently used IPL stadiums based on match data.

4. Man of the Match Analysis

Analyzed players receiving the highest number of Man of the Match awards.

5. Season-Wise Performance

Compared IPL team performances across different seasons.

6. IPL Title Winners

Analyzed season-wise IPL champions, runners-up, final match performers, and Player of the Series information.
